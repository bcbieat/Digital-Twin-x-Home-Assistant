สรุปงานประจำวัน

แผนดำเนินงานวันนี้

  • ตรวจสอบว่า geometry ไม่มี orphan หรือหลุดจาก parent, อยู่ต่ำกว่าพื้น หรือซ้อนทับอุปกรณ์อื่นโดยไม่ตั้งใจ โดยพิจารณา world-space bounds และช่วงแกน Z ร่วมกับ XY
  • บันทึก QA report ก่อน–หลัง: parent/hierarchy, floor clearance, malformed metadata, duplicate role และ collision ที่พบ พร้อมแยกรายการที่ตั้งใจให้สัมผัสหรือฝังกับผนัง
  • บันทึกข้อมูลที่ยังต้องยืนยันจากหน้างาน ได้แก่ ขนาดจริง รุ่นอุปกรณ์ ความสูงติดตั้ง แนวเดินสาย และระดับความเชื่อมั่นของตำแหน่ง
  • ยืนยัน stable object ID, room ID, parent และ selectable node ของ breaker, switch และ outlet เพื่อรองรับ mapping กับ Home Assistant
  • สร้าง render close-up ของตู้เบรกเกอร์ 6 ช่อง สวิตช์ และเต้ารับ เพื่อตรวจ scale, เงาสัมผัส, material, clearance และการบังอุปกรณ์
  • เพิ่มรายละเอียดแบบไม่ทำลายโครงสร้างเดิม เช่น bevel รอยต่อ ปุ่มกด หน้ากาก ขั้วต่อ และสายหรือจุดยึดที่เหมาะสม โดยใช้ child/parent-relative และไม่เปลี่ยน manual transform
  • ตรวจ coordinate/placement contract และเตรียม export validation ของ GLB แยก A3/A4 เฉพาะเมื่อ QA ผ่าน โดยตรวจ origin, axis, scale, floor clearance, object names และ texture
  • เก็บ baseline สำหรับหน้าเว็บ ได้แก่ขนาด GLB, polygon/draw-call โดยประมาณ, load time/FPS และ mapping schema ที่ mark entity ซึ่งยังไม่ยืนยันเป็น placeholder-unverified
Definition of Done: มี QA summary และ close-up ครบ 3 กลุ่มอุปกรณ์, ไม่มี detail ใหม่ที่ orphan/ต่ำกว่าพื้น/ชนโดยไม่ตั้งใจ, protected manual objects และ transforms ไม่เปลี่ยน, มี field blockers ที่ระบุรายการชัดเจน และ export/performance/mapping พร้อมสำหรับขั้นถัดไปเมื่อ gates ผ่าน
