📐 1. สถาปัตยกรรมการปั้นโมเดลใน Blender (3D Hierarchy)

ห้ามรวม Mesh ของตู้เบรกเกอร์เป็นชิ้นเดียว (Do NOT Join Objects) เพราะโปรแกรมเมอร์ต้องเขียนโค้ดจับคันโยกของแต่ละช่องมาหมุนแยกกัน: 

PANEL_A3_DISTRIBUTION_BOARD (Empty Group)
├── Panel_Outer_Casing (กล่องฝาครอบตู้)
├── Panel_Door_Hinge (ฝาเปิด-ปิดโปร่งแสง)
├── Din_Rail_Bar (รางเหล็กยึดโมดูล)
│
├── BREAKER_SLOT_01_LIGHT (Group)
│   ├── Body_Base (ตัวเครื่องพลาสติกเทา)
│   ├── Label_Text ("LIGHT A3 10A")
│   └── LEVER_PIVOT_01 (Origin อยู่ที่แกนหมุน)
│       └── Lever_Thumb_Mesh (ก้านโยกสวิตช์)
│
└── BREAKER_SLOT_02_AC (Group)
    ├── Body_Base
    └── LEVER_PIVOT_02
        └── Lever_Thumb_Mesh

หัวใจสำคัญเรื่อง Pivot Point:

  • เลือกชิ้นส่วน LEVER_PIVOT ➔ กด Tab เข้า Edit Mode ➔ เลือก Edge ตรงแกนหมุน ➔ กด Shift + S ➔ Cursor to Selected
  • ออก Object Mode ➔ คลิกขวา ➔ Set Origin ➔ Origin to 3D Cursor
  • ทดสอบกด R แล้วหมุนตามแกน X: คันโยกต้องดีดขึ้น-ลงเป็นมุม 45° สวยงามโดยไม่หลุดจากร่อง
💻 2. การควบคุมคันโยกผ่านโค้ด 3D (Three.js Kinematics)

บนแพลตฟอร์ม Web 3D เมื่อมี Event เปลี่ยนสถานะ (เช่น ได้รับสัญญาณจาก Home Assistant หรือผู้ใช้คลิก): 

// 1. ดึง Object คันโยกจากชื่อที่ตั้งไว้ใน Blender
const leverA3Light = scene.getObjectByName("LEVER_PIVOT_01");

// 2. กำหนดมุมองศาการหมุน (Radians)
const ANGLE_ON  = 0.785;  // +45 องศา (ดีดขึ้น = เปิดไฟ)
const ANGLE_OFF = -0.785; // -45 องศา (ดีดลง = ตัดไฟ)

// 3. สั่งหมุนคันโยกด้วย GSAP หรือ Tween.js ให้สมูท
function setBreakerState(leverMesh, isPowered) {
  gsap.to(leverMesh.rotation, {
    x: isPowered ? ANGLE_ON : ANGLE_OFF,
    duration: 0.2,
    ease: "power2.out",
    onComplete: () => {
      // ส่งผลกระทบตัดไฟหลอดไฟลูกข่าย
      updateCircuitLoads("CIRCUIT_A3_LIGHT", isPowered);
    }
  });
}

Two-Way Sync Logic:

ถ้าเบรกเกอร์ช่อง A3 ดับ ➔ หลอดไฟ light.a3_main บนโมเดล 3D ต้องดับทันที และระบบต้องล็อกไม่ให้ผู้ใช้กดปุ่มเปิดไฟในห้องนั้นได้จนกว่าจะสับเบรกเกอร์ขึ้น

📋 3. โครงสร้างตาราง Circuit-to-IoT Mapping (โครงร่างเตรียมกรอกข้อมูลหน้างาน)

ตารางนี้จะใช้จับคู่ระหว่าง ตำแหน่งเบรกเกอร์ในตู้ กับ โหลดไฟฟ้าจริงในห้อง A3-A4 และ Entity ID ใน Home Assistant

ตู้ / ช่อง (Slot) ป้ายระบุหน้าตู้ (Panel Label) พิกัดโหลดในห้อง (A3 / A4) อุปกรณ์ไฟฟ้าที่ควบคุม (Connected Fixtures) Home Assistant Entity ID ที่เกี่ยวข้อง การสั่งการ (Control Capability)
DB-A3 / 01 Main Incomer 63A ทั้งห้อง A3 เมนควบคุมไฟทั้งหมดของห้อง A3 switch.a3_main_breaker (ถ้ามีสมาร์ตมิเตอร์) แสดงสถานะเสมือน (Digital Simulation)
DB-A3 / 02 Lighting A3 10A เพดาน A3 หลอดไฟติดเพดาน A3 (กลางห้อง + ไฟสปอตไลต์) light.a3_ceiling_main จำลองสับคันโยก ➔ สั่ง HA Toggle Light
DB-A3 / 03 Air Conditioner 16A ผนังฝั่งซ้าย A3 เครื่องปรับอากาศ A3 climate.a3_air_conditioner สับลง ➔ ตัดไฟแอร์ในระบบ 3D ทันที
DB-A4 / 01 Main Incomer 63A ทั้งห้อง A4 เมนควบคุมไฟทั้งหมดของห้อง A4 switch.a4_main_breaker แสดงสถานะเสมือน
DB-A4 / 02 Lighting A4 10A เพดาน A4 หลอดไฟติดเพดาน A4 + โคมไฟตั้งพื้นมุมโซฟา light.a4_ceiling_main, switch.a4_floor_lamp จำลองสับคันโยก ➔ สั่ง HA Toggle Light
DB-A4 / 03 Air Conditioner 16A ผนังฝั่งซ้าย A4 เครื่องปรับอากาศ A4 climate.a4_air_conditioner สับลง ➔ ตัดไฟแอร์ในระบบ 3D ทันที
📸 4. รายการ Checklist สิ่งที่ต้องถ่ายรูปและจดบันทึกหน้างาน (วันพรุ่งนี้)
  • 1. ถ่ายภาพหน้าตรงของตู้เบรกเกอร์ห้อง A3 และ A4 แบบระนาบตรง (Orthographic Angle)
    ถ่ายแบบไม่เอียง เพื่อนำมาใช้เป็นภาพ Reference Image สำหรับกาง UV Texture และวัดสัดส่วนใน Blender
  • 2. ถ่ายภาพซูมเจาะป้ายชื่อ (Labels) ของเบรกเกอร์ทุกช่อง
    บันทึกตัวหนังสือให้ชัดเจนว่าช่องไหนเขียนว่าอะไร (เช่น แอร์, แสงสว่าง, เต้ารับ, ปั๊ม ฯลฯ)
  • 3. สังเกตและบันทึกรูปลักษณ์ของคันโยกสวิตช์ (Lever Thumb)
    ดูว่าคันโยกดีดขึ้นคือ ON หรือลงคือ ON, มีแถบสีบอกสถานะ (เขียว/แดง) ในช่องหน้าต่างจิ๋วหรือไม่
  • 4. วัดขนาดภายนอกของตู้เบรกเกอร์ (กว้าง x สูง x ลึก) และความสูงจากพื้นห้อง
    เพื่อนำมาวางในโมเดล 3D ให้ตำแหน่งและความสูงบนผนังตรงกับห้องจริง 100%
  • 5. สอบถามช่างอาคารหรือผู้ดูแลระบบเรื่องวงจรไฟฟ้า (Circuit Schedule)
    ยืนยันว่าเบรกเกอร์แต่ละช่องต่อพ่วงกับหลอดไฟดวงไหน ปลั๊กตัวไหน หรือแอร์ตัวไหนบ้าง
  • 6. สอบถามทีม IoT/Home Assistant ว่าตู้ไฟมีโมดูลอ่านค่าหรือสั่งการจริงหรือไม่
    ตรวจดูว่ามีอุปกรณ์อย่าง Sonoff DualR3, Tuya Din-Rail หรือ CT Clamp วัดกระแสติดตั้งอยู่ในตู้หรือไม่
